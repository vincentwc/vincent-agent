项目名称: vincent-agent

## 系统架构分析 (Python/FastAPI)

这是一个基于 FastAPI 的 Python 项目，包含以下层次结构：

### 1. 接口层 (API Layer)
- server (server.py): 无显式路由
- knowledge_base (api/routes/knowledge_base.py): GET /config, POST /create, GET /list, GET /{kb_id}, PUT /{kb_id}
- index (api/routes/index.py): GET /

### 2. 业务服务层 (Service Layer)
- knowledge_base_service: KnowledgeBaseService

### 3. 数据基础设施层 (Infrastructure Layer)
- db: DBManager
- vector_store: MD5Manager, VectoreStoreService

### 4. 数据模型 (Data Models)
- models: Base, KnowledgeBase, KnowledgeDocument
- knowledge_base: KBBase, KBCreateRequest, KBUpdateRequest, KBResponse, DocumentResponse
- factory: BaseModelFactory, ChatModelFactory, EmbeddingModelFactory

### 5. 组件依赖关系
- knowledge_base_service ⤳ db
- knowledge_base_service ⤳ vector_store
- knowledge_base → knowledge_base_service
- db ⤳ db
- vector_store ⤳ db
- vector_store ⤳ vector_store
